## Viewer panel: round 1 changes
- **Length.** It was too long, so I cut to about 115 words.
- **Wording.** "Lost / gone" became "value fell … gone on paper", because this is market value, not cash.
- **One figure.** $1.8T is used everywhere, and $5.8T for the peak.
- **₹ figure.** It now applies only to the lost value, at a stated rate (₹91/$).
- **Scene 6 (high risk).** It was vague, so it now names the concrete thing (local ballot rules on data centres) with a ballot visual.
- **Scenes 7 and 9.** They contradicted each other, so the question is now "is that demand real?" and the answer is "sales still doubling, investors doubt it lasts".
- **"Not yet".** It sounded like a prediction or financial advice, so I removed it.
- **CEO line.** It now uses Bloomberg's verb ("resigns" → "stepped down"), with no allegations.
- **Ending.** It loops back to the hook frame.
- **Not changed.** The panel suggested cutting the spoken "Follow InvisiTech for more". It stays, because rule 21 requires it.

## Viewer panel: round 2 changes (final round, script locked)
- **Scene 7.** It was high risk for Riya, so the loop is spelled out: "invests in AI start-ups, who then buy its chips".
- **Scene 10.** It was high risk because it was too abstract. It now says "A share price is a bet on the future. The bet flipped, not the business." This also answers the objection that the money was "gone".
