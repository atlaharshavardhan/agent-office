      How it works

      1. Agents are files in .claude/agents/. Adding or editing one here changes that file, so Claude Code uses it right away.
      2. Teams group agents. Each team has a lead and a list of teams it can message.
      3. Messages live in .claude/agent-office/messages/. When an agent starts, it is told its team and shown the latest messages to its team, and it can reply by writing a message file.
      4. Live activity comes from Claude Code hooks: each agent's start, tool use and finish.
