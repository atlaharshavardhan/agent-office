## Fact check
| Claim | Check |
|---|---|
| 8 blinks (bits) = 1 letter | Standard 8-bit character (ASCII / UTF-8 for English letters). |
| "Hello" = 40 blinks | 5 letters × 8 bits = 40. |
| A billion blinks a second on a wire | Gigabit Ethernet = 1,000,000,000 bits per second. |
| Router reads addresses, passes data on | What a router does. A home router also has a switch and Wi-Fi built in. |
| Each device has an IP address | Yes (on home Wi-Fi, a local one like 192.168.x.x). |
| Data split into packets, each with the address | Every IP packet carries a source and a destination address. |
| Light bounces inside glass fibre | Total internal reflection in the fibre core. |
| Over 99% of data between continents goes by undersea cable | TeleGeography (US Congress testimony) and the ITU. |
| Hundreds of cables | About 570–600 cable systems in service (TeleGeography, 2025). |
| Anchors and fishing cut cables 150–200 times a year | ICPC: about 150–200 faults a year, 70–80% from fishing and anchors. |
| Mumbai is India's main landing point | Carnegie (2026): the Mumbai coast handles about 95% of India's international bandwidth. |
